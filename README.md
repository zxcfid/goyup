# GoyUP — Telegram Mini App (GitHub Pages)

Готовый к публикации статический сайт **GoyUP** с автоматической локальной базой данных (`IndexedDB: GoyUP_DB` + резервное сохранение в `localStorage`).

## Быстрый запуск на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `goyup-app`).
2. Загрузите файлы из этого архива (`index.html`, `.nojekyll`, `README.md`) в корень репозитория (ветка `main`).
3. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)`** и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
